# Prácticas de Arduino

Prácticas de clase (2023): LEDs, semáforos, botones con resistencias pull-up y pull-down, servomotor y una sirena con buzzer. Incluye las simulaciones en Proteus y los reportes.

**Herramientas:** Arduino, Proteus
