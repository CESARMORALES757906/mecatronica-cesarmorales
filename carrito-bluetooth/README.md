# Carrito Bluetooth

Carrito controlado desde el celular por Bluetooth: el Arduino recibe comandos por el puerto serie y maneja dos motores con el driver L293B (septiembre de 2023).

**Herramientas:** Arduino, módulo Bluetooth HC-05/HC-06, driver L293B
